# 装備自体の考証

weapons、またはintegratedでW軸を使うときに読む。共通規則は[evidence-policy.md](evidence-policy.md)。

| 軸 | 抽出すること |
| --- | --- |
| W1 | 名称・地域・年代・型式・派生型・来歴、開発／採用／配備、現存／復元 |
| W2 | 形状・寸法・質量・材料・機構・動力・作動原理・構成・装備状態 |
| W3 | 公称／試験／推定性能、指標・単位、射程・精度・速度・持続・防護、試験条件 |
| W4 | 操作者・人数、携行・展開・訓練・信頼性・整備・補給・輸送・環境適合 |
| W5 | 武器・防具・搭載機・センサー・通信・制御の関係、時代・構成の整合と条件 |

刀剣・槍・弓・銃砲、防具・装甲、車両・航空機・艦艇、誘導・センサー等を、対象の時代と公開情報の範囲で扱う。実在する計画・試作はweapons、架空・未来創作装備は明示されたfiction拡張。地域・時代・装備名だけで型式を同定しない。

surveyでは原稿なしで名称・年代・構造・所在を整理する。compareでは装備を別equipment_idにし、型式・改修・輸出仕様・構成・測定条件・指標を揃える。reviewでは混同した命題を分ける。

- 採用と配備、史料成立年と現存品の年、現存と復元、年代推定と確定、伝承来歴と裏付けを分ける。
- 最大射程／有効射程、理論発射速度／持続速度、最高速度／通常運用速度、搭載可能／特定構成での搭載・運用は別。口径・重量・名称の一致だけで性能・互換性を断定しない。
- 原表記・概数・範囲・単位・指標定義・型式・構成・測定条件・箇所を残す。換算は元値・式・丸めを残し概数を精密化しない。食い違いを無断訂正せず、未記載条件や非公開性能は保留する。
- 防護規格の版・追補・試験対象・条件と製品適合記録を確認する。要件と試験結果、規格の存在と特定製品の適合は別。等級から全対象・環境で無傷とはしない。メーカー・運用組織の公表を独立試験と称しない。
- 持続運用では操作者・訓練・携行・補給・整備・環境の制約を追う。センサーの検出・計算は操作・命中・身体実行を自動保証しない。

数値を記録する場合は[record-contract.md](record-contract.md)のmeasurementsを使う。測定値の出典と状態を保ち、仮定計算を実測へ置き換えない。
