# 配布物を実行時に必要なものだけへ絞る

- 状態: accepted（2026-11-03、ユーザー依頼「絞って検証する」）
- 置き換え対象: [explicit-package-boundary.md](explicit-package-boundary.md)の「既存の公開済み検証記録を配布に残す」部分。一覧方式は維持する。

## 仮説と成功指標

実行時に読まれない資料（初期設計メモ、ADR、評価の結果と実行記録、評価用スクリプト、テスト）を配布から外しても、スキルの動作は変わらず、導入物は小さくなる。

成功条件: (1) 配布物が実行時に必要なものだけ、(2) SKILL.mdと参考資料の本文が不変（リンク1行を除く）、(3) 配布内の相対リンクが全て配布内で解決、(4) 旧版から更新して残骸が残らない、(5) 全テスト合格。撤退条件: 実行時に必要なファイルの欠落、またはリンク切れが出る。

## 計測（配布前後）

実行時の読込量は変えない（SKILL.md 4,562字、参考資料11本は不変）。変わるのは導入物だけ。

| | 変更前（0.2.3） | 変更後（0.3.0） |
| --- | --- | --- |
| 配布ファイル数 | 106 | 41 |
| 導入先1か所のディスク | 936KB | 288KB |

## 決定

- 配布から外す: 01〜03とcodex-implementation-prompt、adr/、evals/、docs/validation.md・provenance.md・original-files.json、評価用スクリプト、scripts/tests/。いずれも配布元リポジトリに残し、証拠と来歴は失わない。元ファイルのハッシュ固定テストも配布元で維持する。
- 配布物内から配布外を指すリンクは、配布元リポジトリのURLにする。テストが、配布内のリンクは配布内で解決することを検査する。
- installerの必須ファイルとフォルダを実行時の最小に合わせる。テストは配布元で実行する（README記載）。
- 版は0.3.0（配布内容の契約変更）。更新は管理済みコピーを置換し、旧配置の除外ファイルは削除される。

## 非機能要件と機会費用

秘密情報・個人情報・依存・費用の変更はない。導入先でテストを実行できなくなる（配布元で実行する）。配布外の資料はURLで辿るため、オフラインの導入先では読めない。実行には不要。

## レビュー結果

Antigravity（agy、plan）の静的レビューを受けた。採用: READMEに新ADRへのリンク追加、配布内docs/feedback.mdのテストコマンドに配布元実行の注記。不採用: 差分欠落の指摘（レビューへ渡した差分にpackage-files.txtと新ADRを含めなかったため）、import漏れ（既存importで解決済み）。更新時の残骸は既存の古いファイル削除テストと、旧0.2.3導入物を0.3.0へ更新する実測（106→41ファイル、残骸なし）で確認した。Codexは使わなかった（サンドボックス外の起動をせず、Antigravityで足りたため）。
