# 配布物を一覧で固定し、検証ログを分離する

- 状態: accepted（2026-10-31、ユーザー確認済み）
- 対応: GitHub Issue #1。後続は #2（3環境）、#3（報告）、#4（A/B評価）。

## 仮説と成功指標

再帰コピーを明示的なファイル一覧に置き換えると、後から追加された私的原稿や検証ログの配布を防げる。成功条件は、一覧外ファイルの混入ゼロ、一覧内の必要ファイル保持、Gitなしでの導入・更新・削除、既存の手編集保護と復旧処理の維持。

配布欠落・相対参照の破損・既存導入の破損があれば採用を止めて修正する。モデル回答の正確性はこの変更の成功指標ではない。

## 要件・調査

mece-cluster-advisorの追跡対象限定と*.local.md除外、official-prompt-tailorのfeedback/運用を参照した。Git追跡ファイルの実行時取得は採用しない。GitのないZIP展開元にも対応するためである。既存のPython標準ライブラリ、所有権記録、置換前検査と復旧を再利用する。依存は追加しない。

## 配布モデルと決定

`package-files.txt`を配布物の正本一覧とする。相対POSIXパスのみで、重複・必須項目欠落・上位参照・リンク・存在しないファイルを拒否する。feedback/、隠しパス、*.local.md、Pythonキャッシュは一覧に含まれても拒否する。追加ファイルはレビューして一覧を更新する。既存の公開済み検証記録は再現用の資料として明示的に残し、新たな実行記録はfeedback/へ保存する。

READMEは導入方法を維持し、配布一覧と検証ログの扱いを案内する。実装範囲はscripts/skill_installation.py、配置テスト、配布物検査、.gitignore、docs/compatibility.md。後続Issueはこの境界を守って必要なファイルを追加する。

## 非機能要件と機会費用

秘密情報・個人情報・未公開原稿はfeedback/にも原則残さない。ログを外部へ自動送信しない。公開テンプレートは空または合成例だけとする。配布元にアクセスする権限の境界でパスとリンクを検査する。新規依存・ライセンス変更・API費用は発生しない。文書は平文とMarkdownで読みやすく保つ。配布一覧の更新作業が増えるが、暗黙の再帰コピーによる混入より予測しやすい。

## 検証

- [x] 不正パス・重複・欠落・ファイルと親のリンクを拒否する。
- [x] Gitのない一時配置から導入・更新・削除し、guard/renderを実行できる。
- [x] 配布物の相対文書リンクが解決し、既存テストが通る。
- [ ] 他エージェントレビューの指摘を検討し、結果をIssueへ残す。
